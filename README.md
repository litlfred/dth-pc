# dth-pc

The WHO **Digital transformation handbook for health product catalogue** (2025, ISBN 9789240116191), as an L2 Digital Transformation Handbook on [smart-ra](https://github.com/litlfred/smart-ra) and [dth-sc](https://github.com/litlfred/dth-sc): narrative validated against the glossaries and linked to the DPI-H ArchiMate model.

- Working document: `folio/dth-pc/`, seeded from the L1 entry [`who-iris/library/9789240116191-eng`](https://github.com/litlfred/who-iris/tree/main/library/9789240116191-eng).
- Product catalogue glossary: `glossary/dth-pc.glossary.json`.
- Plan: [`docs/workplan.md`](docs/workplan.md) (tracked in litlfred/smart-ra#141; issues are off on this fork).
- Agent guidance: [`AGENTS.md`](AGENTS.md).

dth-pc depends on dth-sc (supply chain terms, the DHSC architecture view). [smart-pcmt](https://github.com/litlfred/smart-pcmt) is downstream of dth-pc.

This is a fork of WorldHealthOrganization/dth-pc. Work happens here; nothing is pushed upstream without the owner's say-so.
